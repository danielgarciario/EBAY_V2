# EBAY_V2 Instructions

## Database Work

1. Do not connect to any database for this project.
2. Generate and maintain SQL scripts only.
3. The user validates and executes database scripts manually.
4. Do not use LocalDB, Continum, SQL Server, SQL Server Agent, or any other database connection for validation unless the user explicitly changes this instruction later.
5. Use local Europe/Berlin time in database columns and scripts; do not use UTC naming or UTC defaults.
6. For C# imports into SQL Server, prefer user-defined table types matching DataTables and stored procedures using MERGE for idempotent persistence.
